# CYW43439 firmware blobs

WiFi firmware, country locale matrix (CLM), and NVRAM for the Pico 2 W's CYW43439 chip, embedded by
[src/hal/wifi/access_point.rs](../../src/hal/wifi/access_point.rs).

Copied unmodified from [embassy `cyw43-firmware`](https://github.com/embassy-rs/embassy/tree/embassy-rp-v0.10.0/cyw43-firmware)
(tag `embassy-rp-v0.10.0`), which in turn sources them from
[georgerobotics/cyw43-driver](https://github.com/georgerobotics/cyw43-driver/tree/main/firmware).
